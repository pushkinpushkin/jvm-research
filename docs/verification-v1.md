# Проверка изменений протокола v1

Изменения опираются на `main` commit `492e8a4cfd4954789a6b8279678c54dcc38dba62`. Проверки ниже относятся к реализации, не являются результатами сравнения JVM.

## Выполнено локально

25.09.2026: Java 21 / Gradle 8.14.3 — `test bootJar` успешно, 14 Java tests; 17 Python tests успешно; 10 живых HTTP-проверок WireMock успешно. Синтаксические проверки Bash, Python и JavaScript успешны.

## Проверки

- Python: численные расчёты, детерминированный trace при разном распределении VU, полнота артефактов, отклонение некорректных прогонов, сохранение кода ошибки k6, остановка и cleanup.
- Java: bounded history/cache/receipts, TTL, повторная доставка после ошибки Mongo, receipt после очистки cache, ошибка ACK Kafka и последующий повтор outbox, конкурентные изменения, различение ожидаемого 503/timeout/bad JSON и неожиданного 404/invalid JSON.
- WireMock 3.9.1 standalone: живые HTTP-проверки всех 5 режимов на обоих маршрутах. LONG_DELAY вызывает timeout клиента 2 секунды, SLOW занимает не менее 1.1 секунды, ERROR=503, BAD_RESPONSE=200 с невалидным JSON; обычные ответы имеют ожидаемый бизнес-статус.
- Bash syntax, Python compile, JavaScript syntax для HTML-отчёта.
- CI выполняет Java/Python tests, все WireMock mappings и Docker smoke HotSpot/OpenJ9/GraalVM JIT/Native с elastic-профилями JVM.

## Что ещё проверять на стенде

1. Docker smoke всех четырёх runtime; сборка Native и исполнение новых Mongo/Kafka путей.
2. Полная серия `TRAFFIC_PROFILE=faults` и баланс после drain.
3. По 30 минут для каждого runtime, затем минимум 3 повтора по протоколу.
4. Влияние сборщика на слабонагруженный сервис: сравнить одинаковую работу с интервалами 5 и 15 секунд. Docker exec и HTTP telemetry имеют ненулевой overhead.
5. Проверить конкретные image IDs, хост и фактический GC; фиксировать образы до эталонных запусков.

Локальная среда разработки не содержит Docker daemon; тесты с mock-артефактами не заменяют этот пункт. До успешных Docker и длительных проверок нельзя считать стенд полностью готовым к эталонным данным.
