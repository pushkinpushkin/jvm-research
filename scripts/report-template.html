Запуск до readiness

Бизнес HTTP p95

Время ответа, мс. Для idle отсутствует по смыслу.

HTTP p95 по минутам

Доступно при K6_TIME_SERIES=true. Отсчёт от первого бизнес-запроса k6; seed исключён, число запросов в окне видно при наведении.

Выбирайте условия вверху и включайте отдельные линии. Разные memory profile подписаны отдельно: fixed heap, elastic heap и native default имеют разные настройки heap. Для итоговых выводов сравнивайте также ошибки, фактическое число запросов и повторы. Источник данных — metadata.json, runtime-metrics.csv и k6-summary.json; при наличии — k6-timeseries.json.
